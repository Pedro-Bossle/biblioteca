# Biblioteca Farrapos

Estante online do trabalho “Você tem brio?”, do Capítulo Farrapos nº 1111 da Ordem DeMolay: 42 livros com capa, contracapa, lombada, sinopse, autor, dificuldade e link de compra.

Publicada no GitHub Pages: https://pedro-bossle.github.io/biblioteca/

Para atualizar, edite `index.html` (os dados dos livros ficam no próprio arquivo) e as imagens em `capas/`, `capas-g/`, `contracapas/` e `lombadas/`.
